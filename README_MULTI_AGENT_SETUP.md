# UMAN Multi-Agent Control Package

Place these four `.md` files in the **root of the UMAN repository**:

- `AGENT_ENTRYPOINT.md` — short instructions every agent reads first.
- `MULTI_AGENT_PROTOCOL.md` — the full mandatory operating rules.
- `ACTIVE_WORK.md` — live coordination table showing who is working on what.
- `TASK_BRIEF_TEMPLATE.md` — template used to define each new implementation task.

## What you need to do

You do **not** need to edit the contents manually.

1. Copy these four files into the repository root.
2. Commit them to Git together.
3. Before giving any agent a new coding task, create/fill a Task Brief for that task and register the task in `ACTIVE_WORK.md`.
4. Every agent must follow `AGENT_ENTRYPOINT.md`.

If you are unsure how to create the next Task Brief or whether two agents may work in parallel, do not improvise. Bring the current task/status back to ChatGPT and have the coordination prepared for you.
